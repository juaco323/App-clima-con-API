## 🐛 SI HAY PROBLEMAS AL COMPILAR

### Error: "Sync failed"
```
File → Invalidate Caches → Invalidate and Restart
Espera que reinicie
File → Sync Project with Gradle Files
```

### Error: Logo no aparece
```
Build → Clean Project
Build → Rebuild Project
Verifica que los archivos estén en las carpetas mipmap-*
```

### Error: "Unresolved reference"
```
Ya debería estar solucionado (activity-ktx agregado)
Si aparece: File → Sync Project with Gradle Files
```
